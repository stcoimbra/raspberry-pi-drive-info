# Privacy policy

Last updated: October 16, 2026

Raspberry Pi Drive is a personal Google Drive integration maintained
by stcoimbra for the account owner's use.

## Google Drive access

The integration requests read-only access to Google Drive to list
and download selected Python scripts and source files. This permission
can technically read all files accessible to the authorized account,
although the configured workflow targets selected folders.

## Storage and use

Downloaded files are stored locally on the owner's Raspberry Pi
and used for personal data collection and dashboards.

OAuth credentials and tokens are stored locally on the Pi.
They are not published in this repository or on this website.

Google Drive data is not sold, used for advertising, or intentionally
published through this website.

## Retention and control

Local copies remain until the owner replaces or deletes them.
The owner can revoke access through their Google Account's
third-party connections settings. Revoking access prevents future
access but does not remove previously downloaded copies.

## Website hosting

This information website is hosted by GitHub Pages. GitHub may
process visitor information according to its own privacy statement.
