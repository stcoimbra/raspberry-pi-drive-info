# Raspberry Pi Drive

Raspberry Pi Drive is a personal integration maintained by stcoimbra.
It uses rclone to download selected Python scripts and source files
from the owner's Google Drive to a Raspberry Pi for personal data
collection and dashboards.

Google Drive access is read-only. The integration does not modify
or delete files in Google Drive.

This integration is for the owner's personal use and is not offered
as a public service.
